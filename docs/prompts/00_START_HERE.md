# How to use this kit

1. Create a new folder and open it in VS Code. Run `git init`.
2. Put `CLAUDE.md` in the repo root. Save the original spec text as `docs/SPEC.md`.
3. Start Claude Code in the repo. Paste prompts from this folder **one at a time**, in order (01 → 09).
4. After each phase, review the report, run the app, then say "approved, continue" or give corrections.
5. Do not skip the "Verify" section in each prompt.

Tip: if a session gets long, start a new one; CLAUDE.md carries the rules.
